# VOID Network GPL Attribution Terms v1.0

These terms are a narrow GPL-compatible attribution/origin layer for original
VOID Network material in this repository. They do **not** replace the repository's
GNU GPL license and they do **not** import the standalone VOID Community License
(VCL) restrictions into GPL-covered code.

## 1. Scope

These terms apply only to copyrightable material for which 6ZoSo9 / VOID Network
contributors hold the relevant copyright **and** which contains a source notice
pointing to this document.

They do not apply to upstream OpenRA, OpenRA-RL, copied historical fixtures,
third-party libraries, game assets, or any material for which VOID Network
contributors do not hold the necessary copyright.

A recommended source notice is:

```text
Copyright (c) 2026 6ZoSo9 and VOID Network contributors.
GPLv3 section 7 attribution/origin terms:
see /VOID_NETWORK_GPL_ATTRIBUTION_TERMS.md
```

The source notice may be adapted to the file's comment syntax without changing
its substance.

## 2. GNU GPLv3 section 7(b): preservation of attribution

For designated VOID-authored material, preserve the applicable copyright notice
and the pointer to these terms when conveying source copies or modified source
copies of that material.

A repository-level NOTICE may satisfy the attribution presentation requirement
when it accompanies the conveyed source and clearly identifies the applicable
VOID-authored material, unless a file contains a more specific notice that must
also remain intact.

## 3. GNU GPLv3 section 7(c): origin and modification marking

Do not misrepresent the origin of designated VOID-authored material.

If designated VOID-authored material is modified, the modified version must be
marked in a reasonable way as changed and must not be represented as an
unmodified or official VOID Network release.

This does not prevent forks, modifications, redistribution, commercial use, or
independent operation otherwise permitted by the GNU GPL.

## 4. Branding and trademarks

The GNU GPL grants copyright permissions; it does not grant trademark rights.
Use of VOID-related names or branding must not falsely imply sponsorship,
endorsement, or official status. Nominative use to identify or discuss this
project is not restricted by this document.

See `docs/legal/TRADEMARKS.md`.

## 5. What these terms do not do

These terms do **not** add the VCL restrictions that prohibit redistribution,
hosting, SaaS, commercial use, competing networks, or forking.

Those restrictions would be inappropriate as a repository-wide overlay on
GPL-covered OpenRA/OpenRA-RL material.

These terms also do not change the license of third-party material and do not
claim copyright over work created by upstream authors.

## 6. Future VOID-authored files

New original VOID-authored source files that are intended to carry these
section 7 terms should include the source notice described in section 1.

Existing files should not be mechanically re-headered when doing so would break
source-identity, evidence, reproducibility, or accepted hash bindings. Their
copyright provenance remains recorded by repository history and `NOTICE`;
file-level section 7 designation can be added only through a reviewed migration.

## 7. Relationship to the standalone VCL

The VOID Community License (VCL) v1.0 remains the license used by other VOID
Network repositories where its restrictions are appropriate.

This repository is different because it contains GPL-covered upstream material.
Accordingly, this repository remains GPL-covered, with only the narrow
attribution/origin terms above for specifically designated VOID-owned material.
